### 👋 About Me

I'm **Yihan Wang**, a senior undergraduate at **Tianjin University**, focusing on **Agent Post-training**. I'm interested in how language-model agents learn from experience and improve through reinforcement learning.

- 🧠 **Agent learning:** Small-model agents, reinforcement learning, and teacher-trajectory reuse.
- 🔍 **Agent evaluation:** Customer-support benchmarks, rubric design, and knowledge-grounded responses.
- 🌍 **Remote sensing:** Exploring vision-language models and agents for understanding changes in Earth observation imagery.
- 🛠️ **Research tools:** Building tools for literature reading, knowledge organization, and research idea development.

Outside research, I enjoy **strength training, cycling, and badminton**.

### 🚀 Selected Projects

| Project | What I'm working on |
| :--- | :--- |
| **[Prefix-GRPO](https://github.com/HappynessI/Prefix_GRPO)** | Reusing teacher trajectories through replayed prefixes and online continuation for small-model agent training. Includes datasets and training metrics for TextCraft, BabyAI, and ALFWorld. |
| **[HMBB Benchmark](https://github.com/HappynessI/HMBB_Benchmark)** | Customer-support agent evaluation with conversation-derived questions, explicit rubrics, and experiments on knowledge retrieval and response quality. |
| **[Remote Sensing Knowledge Base](https://github.com/HappynessI/RS_Knowledge_Base)** | An Obsidian-compatible research library for remote sensing change understanding, vision-language models, and agents. |
| **[League of Idea](https://github.com/HappynessI/League_of_Idea)** | A literature-grounded workspace for developing, critiquing, revising, and comparing research ideas. |
| **[MinerU PDF to Markdown](https://github.com/HappynessI/MinderU-pdf-to-md)** | A reusable Codex skill for converting papers to structured Markdown and translating them while preserving equations and figure links. |
